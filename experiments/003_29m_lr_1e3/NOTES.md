# LR sweep（002/003/004/007）— 29M 学习率消融

## Goal
在 29M 规模上找到最优学习率，并验证"最优 lr 随规模漂移"是否影响选型。

## Setup
- 模型：29M（8 层 / d_model 512 / 8 头 / d_ff 1344，其余同 001）
- 四组并行（GPU 0/3/6/7），唯一变量是 max_lr：3e-4 / 1e-3 / 1.25e-3 / 3e-3
- 1.25e-3 档为参考项目 Hurricane0698 的实测最优值（对照锚点）
- 其余全同：28500 步（1 epoch）、bs 64×256；min_lr 各组见对应 config.json
- 曲线图：assets/lr_sweep.png

## Results
| lr | best val loss | 现象 |
|---|---|---|
| 3e-4 | 1.4467 | 平稳收敛，欠拟合 |
| **1e-3** | **1.3832**（精确复测 1.3979±0.005）| **最优** |
| 1.25e-3 | 1.3964 | 与 1e-3 曲线几乎重合 |
| 3e-3 | 2.2837（发散） | step ~4000 起 val 反弹至 3.9，gnorm 飙至 ~50，末期回落至 2.6 但无法恢复 |

## Conclusions
1. 最优 lr 落在 1e-3 附近的"平缓盆地"，1e-3 与 1.25e-3 差距（0.013）在噪声边缘
2. lr 过高（3e-3）的发散模式：先正常下降 → 突变反弹 → 缓慢恢复但永久受损
3. 两个参考项目的最优值（1e-3 / 1.25e-3）与本实验互证——该尺度下的最优区间可复现

## Limitations
- min_lr 未严格统一为 max_lr/10（部分组用默认 3e-5），对末端收敛有微小影响
- 单 seed；未测 1e-3 与 1.25e-3 之间的差距是否统计显著（sem ±0.005）
