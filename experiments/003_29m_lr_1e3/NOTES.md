# 003_29m_lr_1e3 — LR sweep：lr=1e-3（冠军组）

## Goal
在 29M 规模上确定最优学习率，并验证"最优 lr 随模型规模漂移"对选型的影响。

## Setup
- 模型：29M（8 层 / d_model 512 / 8 头 / d_ff 1344，其余同 001）
- 四组并行（GPU 0/3/6/7），唯一变量为 max_lr：3e-4 / 1e-3 / 1.25e-3 / 3e-3
- 1.25e-3 档为参考项目 Hurricane0698 的实测最优值（对照锚点）
- 其余条件全同：28500 步（1 epoch）、bs 64×256；min_lr 各组见对应 config.json
- 曲线图：assets/lr_sweep.png

## Results
| lr | best val loss | 现象 |
|---|---|---|
| 3e-4 | 1.4467 | 平稳收敛，欠拟合 |
| **1e-3** | **1.3832**（精确复测 1.3979±0.005）| **最优** |
| 1.25e-3 | 1.3964 | 与 1e-3 曲线基本重合 |
| 3e-3 | 2.2837（发散） | step ~4000 起 val 反弹至 3.9，gnorm ~50，末期回落至 2.6 但未能恢复 |

## Conclusions
1. 最优 lr 位于 1e-3 附近的平坦区间，1e-3 与 1.25e-3 差距（0.013）接近噪声水平
2. lr 过高（3e-3）的发散模式：先正常下降 → 突变反弹 → 缓慢恢复但永久受损
3. 两个参考项目的最优值（1e-3 / 1.25e-3）与本实验相互印证，该尺度下的最优区间可复现

## Limitations
- min_lr 未严格统一为 max_lr/10（部分组使用默认 3e-5），对末端收敛有轻微影响
- 单 seed；未检验 1e-3 与 1.25e-3 差距的统计显著性（sem ±0.005）
